# Titanic-Dashboard
Project Overview
An interactive data visualization dashboard built to analyze passenger demographics, survival metrics, and socio-economic factors from the historic Titanic dataset.

Key Metrics (KPIs)

Total Passengers: 891 tracked individuals in the dataset.

Total Survivors: 342 passengers rescued.

Overall Survival Rate: 38.38% overall survival outcome.

Dashboard Highlights & Visualizations

Class & Survival Breakdown: Stacked bar chart showing survival rates across socio-economic classes (62.96% survival in Upper Class vs 24.24% in Lower Class).

Demographics Analysis: Grouped bar chart depicting total passengers segmented by Age Group (Adult, Teen, Child, Senior Citizen, Unspecified) and Gender.

Deck Allocation & Class Distribution: Treemap layout mapping passenger deck assignments relative to socio-economic class tiers.

Port of Embarkation: Donut chart highlighting passenger boarding distribution across Southampton (72.5%), Cherbourg (18.86%), and Queenstown (8.64%).

Dynamic Slicers: Interactive side panel filters allowing users to slice data by Age Group, Pclass, Sex, Class Label, and Survival Status.
